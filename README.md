# 이름 스프린트

한 컴퓨터에서 참가자들이 자기 이름을 누가 가장 빨리 입력하는지 겨루는 타자 게임입니다.

## 바로 사용하기

GitHub Pages 주소에 접속하면 설치나 로그인 없이 바로 실행됩니다.

- 첫 글자를 입력하는 순간 타이머가 시작됩니다.
- 등록한 이름을 정확히 입력하고 `Enter`를 누르면 기록이 종료됩니다.
- 붙여넣기와 끌어놓기는 사용할 수 없습니다.
- 같은 이름으로 다시 도전하면 더 빠른 기록만 순위표에 남습니다.
- 기록은 현재 브라우저의 `localStorage`에만 저장됩니다.

## 구성

별도의 서버, Node.js, 데이터베이스가 필요 없는 순수 정적 웹사이트입니다.

- `index.html`: 화면 구조
- `styles.css`: 디자인과 반응형 레이아웃
- `script.js`: 타이머와 순위표 기능
